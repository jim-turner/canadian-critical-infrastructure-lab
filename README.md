# Canadian Critical Infrastructure Cybersecurity Laboratory (CMWTF-01)

## Project Description
Designing, implementing, and securing a simulated municipal water treatment facility for OT/ICS cybersecurity research and professional portfolio demonstration.

## Architecture & Standards
- Purdue Enterprise Reference Architecture
- NIST SP 800-82 Rev. 3
- IEC 62443 Compliance Framework

## Environment
The laboratory uses physical networking equipment and virtualized infrastructure running on Proxmox. All industrial processes are fully simulated. No connection to operational municipal infrastructure or real industrial control systems is involved.
